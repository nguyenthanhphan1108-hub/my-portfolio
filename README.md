# 🎨 Modern Bento Portfolio

A personal portfolio website with modern and minimalist design, built using **Bento Grid Layout**. This portfolio project features responsive design and dark/light mode capabilities using CSS Grid technology.

## 📋 About The Project

This project is a personal portfolio website developed using the modern web design trend of Bento Grid Layout. Inspired by Apple's macOS design language, this layout offers an aesthetic appearance where content is organized in different sized cards.

## 🎨 Design Features

### Card Types

- **Profile Card** - Personal information and CTA button
- **Skills Card** - Technology skills list
- **Stats Card** - Statistical information
- **Image Card** - Profile image/animation
- **Project Card** - Project showcase area
- **Social Card** - Contact links

### Color Palette

- **Light Mode**: Clean white cards, soft gray background
- **Dark Mode**: Dark slate colors, purple accent
- **Accent Color**: Indigo gradient (#6366f1 - #818cf8)

## 🎯 Customization Guide

### 1. Update Personal Information

Edit the personal information in [index.html](index.html) file according to yourself:

- Name and title information
- About text
- Skills list
- Contact information

### 2. Change Colors

Customize colors by editing the CSS variables at the beginning of [style.css](style.css) file:

```css
:root {
  --accent: #your-color;
  --card-bg: #your-background;
  /* other colors... */
}
```

### 3. Update Images

Replace the images in `images/` folder with your own images.
